# Проверка трея

Нативный тест требует Cinnamon/X11 и видимый XApp monitor:

```sh
dotnet run --project tools/TrayProbe
```

Создаёт отдельный тестовый значок, панель с номером 701 и кратковременно
показывает меню. Проверяет XApp ButtonPress/ButtonRelease правой кнопки,
светлую/тёмную палитру, SNI-сериализацию свойств, раздельные активацию и
контекстное меню, красный значок offline. Снимки сохраняет в отдельный
временный каталог, путь печатает. Курсор не перемещает. Рабочий профиль,
службы EliteSIP, SIP и звуковые устройства не запускает и не меняет.

SNI без графики, на **изолированной** шине, с тестовым наблюдателем:

```sh
dotnet build tools/TrayProbe
dbus-run-session -- env XDG_CURRENT_DESKTOP=Test ELITESIP_TEST_SNI=1 \
  dotnet run --project tools/TrayProbe --no-build
```

Этот режим проверяет экспорт пикселей, раздельные методы ContextMenu/Activate
и восстановление регистрации при исчезновении и возврате наблюдателя.
Не запускайте режим ELITESIP_TEST_SNI=1 на обычной пользовательской шине.
Оба режима возвращают ненулевой код при ошибке.

## История и буфер X11

`ELITESIP_TEST_HISTORY=1 dotnet run --project tools/TrayProbe` запускает только тестовые
окна истории и панели с вымышленными записями. Сохраняет светлую/тёмную историю,
плоский календарь и отключённый профиль в `/tmp/elitesip-tray-probe-*`.
После закрытия истории отдельный GTK-процесс трижды запрашивает изображение из
буфера X11: это воспроизводит отложенный запрос, вызывавший ObjectDisposedException.
Требуется `/usr/bin/python3` с GTK 3 (PyGObject). Проверка заменяет содержимое буфера
тестовым снимком; настройки, аккаунты, SIP и аудио не запускаются.

Режим истории также показывает вымышленные раздачу и звонок по сделке и сохраняет
`incoming-*-x11.png` отдельным GDK/X11-процессом. Это захват реальной поверхности окна,
включая внешние края, а не только рендер содержимого Avalonia.
