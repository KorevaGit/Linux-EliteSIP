# Первичная нативная приёмка Linux — 16 ноября 2026

Проверены исходники после UI-этапа `8af8881` на Linux Mint 22.3, Cinnamon,
Mutter/Muffin, X11 `:0`, 1920×1080, масштаб 1. Рабочая область 1920×1040.
Доступ к сеансу выполнялся вне песочницы; ошибка доступа внутри неё не
означает отсутствие X11 или аудиосервера.

## Выполнено

- `dotnet run --project tools/WindowProbe --no-restore`: отдельное стендовое
  окно без `--inject`, без движения курсора и синтетических щелчков. Фокус
  остался у исходного окна; позиция 187,173 совпала с запрошенной; окно
  верхнее в стопке, с ABOVE и SKIP_TASKBAR. Размер клиента 320×212.
  Это проверка нативного механизма показа, а не полного продуктового окна
  входящего и его защиты от случайного приёма.
- `dotnet run --project tools/PulseProbe --no-restore -- catalog`: найден
  встроенный микрофон и встроенный выход, 48 кГц, два канала. Сервер —
  PulseAudio поверх PipeWire 1.0.5. USB/Bluetooth в каталоге отсутствуют.
- `dotnet run --project tools/PulseProbe --no-build -- engine --seconds 10`:
  продуктовый тракт PCMU, вход с микрофона, выход — тишина, без сохранения
  записи и без SIP-вызова. Баланс сходится; разрывов, переполнений захвата,
  дыр сервера и недоборов вывода — 0. Отправлено 495 кадров из ~499 (99,3%).
  Задержка эхоподавителю в конце 54 мс. Оценка ухода часов за 10 секунд
  недостаточна для вывода о длительной стабильности. Стенд сообщил усиление
  микрофона +59 дБ к базовому; системная громкость не изменялась.

Исходные журналы текущего рабочего места: `/tmp/elitesip-accept-window.log`,
`/tmp/elitesip-accept-audio.log`, `/tmp/elitesip-accept-engine.log`.
Они временные и не содержат записи звука.

Полный клиент: сохранённые обои и заставка, максимизация и минимумы окон,
разные DPI, трей, буфер обмена, входящий без активации, перемещение и защита

## Debug-пакет

В `tools/build-deb.sh` добавлен `--configuration Debug`; Release остаётся
значением по умолчанию. Debug отключает ReadyToRun, сохраняет PDB и имеет
суффикс `-Debug.deb`. Обе программы собираются в одной конфигурации.
Команда для локального доверенного теста:

```sh
tools/build-deb.sh --version 0.1.7 --configuration Debug \
  --provisioning ~/.config/EliteSIP-release/provisioning.linux.json
```

Пакет не устанавливается и не публикуется автоматически. Установка заменит
обычный клиент в `/opt/elitesip`; отдельной установки рядом нет. Версия
исходников остаётся 0.1.7, выпуск в производственный канал не выполняется.
