# Контрольные снимки

История, календарь, отключённый профиль — нативный Avalonia/Skia стенд на X11.
`incoming-*-x11.png` — захват реальной X11-поверхности входящих отдельным GDK-процессом.
Меню, обработка, самопроверка и управление — Avalonia Headless/Skia с теми же шаблонами.
Профили и записи вымышленные. Диаграмма записи в контрольном снимке получает
тестовые значения только из теста; в продукте она подключена к реальному микрофону.
Английские подписи соответствуют культуре тестового процесса.

Три внешних GTK-запроса снимка после закрытия истории получили PNG 1404×868;
приложение осталось живо. Итог: 93 UI + 121 тест модели прошли.
