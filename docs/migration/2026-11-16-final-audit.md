# Аудит перед выпуском Linux, 16 ноября 2026

Проверена текущая ветка dev после переноса дизайна, истории, трея, обоев и
ранней заставки (до аудита HEAD b68a644). Это аудит, не выкладка.

## Исправлено по результатам проверки

История, настройки и управление при повторной команде вызывали только
Activate, оставляя WindowState.Minimized. Общий RestoreAndActivate сначала
восстанавливает Normal и затем активирует уже существующее окно. Окно в
Maximized не нормализуется. Три проверки настоящих команд App сначала
упали, после исправления прошли. Нативный ELITESIP_TEST_REOPEN=1 подтвердил
Normal, IsVisible и IsActive для всех трёх окон на Cinnamon/X11.

GitHub Actions был включён, но push-триггер CI исключал рабочую ветку dev
(только main и linux/**), поэтому для неё не было прогонов. dev добавлена
в триггер: сборка, все тесты, пакет и установочные проверки теперь запускаются
для каждого её push.

## Проверки кода и выпуска

- Полная Release-сборка решения: 0 ошибок, 0 предупреждений.
- Полный Release-прогон: 1409 прошли, 2 пропущены, 0 ошибок (15 наборов).
  Пропуски платформенных проверок Windows в MediaCore и CallHistory;
  предупреждения как ошибки не отключались.
- Первый Debug-прогон: один сбой теста SIP 183/SDP. Последующий полный
  SIP-набор (357), 20 отдельных повторов этого теста и полный Release-прогон
  прошли. Причина первого сбоя не установлена; это наблюдение не считается
  исправленным дефектом. При повторении сохранить TRX/stack trace и остановить
  выпуск до диагностики, а не скрывать сбой перезапуском CI.
- bash -n для build-deb/release/publish и sh -n для maintainer scripts прошли.
- git diff --check прошёл. Gitlinks и сборочные ссылки на Windows отсутствуют;
  независимость Linux соответствует ADR 0001. Секретные provisioning/ключи
  не отслеживаются Git.
- Просмотрены владение clipboard, жизненный цикл заставки, ресурсы темы,
  доставка tray actions, maintainer scripts и разделение ролей обновляльщика.
  Дополнительных подтверждённых блокирующих ошибок кода не обнаружено.
- X11-проверки снимка истории после закрытия окна, обоев входящего и заставки
  выполнены на предыдущем этапе и описаны в 2026-11-16-wallpaper-splash.md;
  этот аудит не выдаёт их за новый прогон.

## Границы готовности

Код прошёл локальные проверки и готов к пилотной приёмке. Массовую выкладку
пока не считать подтверждённой: текущая исходная версия 0.1.7, тестовый Debug
пакет не является подписанным новым выпуском. Нужны:

1. Новый номер выше 0.1.7 через штатный release.sh, Release-пакет, подпись
   отдельным Linux-ключом, успешный publish.sh --dry-run.
2. Успешный CI именно коммита выпуска (локальный прогон не заменяет CI).
3. На отдельном Mint 22/X11: чистая установка, запуск от обычного оператора,
   регистрация/входящий/исходящий со звуком, перезапуск, автостарт и обновление
   поверх 0.1.7 через подписанный канал с проверкой started и журнала службы.
   Эти действия не выполнялись на рабочей системе во время аудита.
4. Пилот на одной машине перед общим каналом. Wayland вне целевой приёмки
   Mint/Cinnamon/X11 и отдельно не проверен.

## Откат

До выкладки сохранить предыдущие проверенные .deb и подписанный current.json.
При падении запуска, невозможности звонка/приёма/звука или установки обновления
остановить распространение и вернуть предыдущий манифест. Это остановит новые
обновления, но не понизит уже обновившиеся клиенты: им администратор ставит
проверенный предыдущий .deb через apt с разрешённым downgrade. Настройки и
историю оператора предварительно сохранить; автоматический откат совместимости
данных этим аудитом не проверен. После исправления публиковать более высокий
номер, не заменять пакет под уже опубликованной версией.
