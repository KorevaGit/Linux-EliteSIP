# История, отключённый профиль и выпадающие меню

Доработка после пользовательской проверки Debug `3e4c113` от 16 ноября 2026.
Linux остаётся независимым. Донор дизайна истории — Windows `13bba4436a035f2e62adc79945e2aa0d4c7a1f8e`,
`History/CallHistoryWindow.xaml`, `GraphiteHistory.xaml` и значения `History*` в палитрах.
Код и ресурсы скопированы/адаптированы явно, зависимости от Windows нет.

## Причины и исправления

- Команды отключения меняли модель, но Linux-капсула всегда показывала номер и имя.
  Как на Windows, теперь онлайн-идентичность заменяется подписью «Отключён»;
  обратное переключение восстанавливает номер/имя. Заголовок «ВАШ НОМЕР» сохраняет номер.
- Поле языка растягивалось на высоту строки 55. Высота теперь 32 с выравниванием по центру.
- ComboBox SimpleTheme задавал фон popup внутри шаблона с приоритетом выше внешнего стиля.
  Общие фирменные шаблоны ComboBox/ComboBoxItem и ContextMenu/MenuItem действуют
  в настройках, управлении и остальных окнах, включая вложенные меню. Используются
  динамические ресурсы палитры, состояния выбора/наведения и скругления.
- История сохраняла старую геометрию. Теперь фильтры и кнопки высотой 40,
  значки строк 40, заголовки 18, отдельные колонки времени/даты и результата,
  разделители строк, скрытая подпись сегодняшнего дня и Windows-цвета значков.
- Всплывающий календарь плоский: однотонный фон, без теней, градиентов и выпуклых
  кромок на днях и кнопках перелистывания.
- Снимок освобождался сразу после SetBitmapAsync. Настоящий X11 позднее запрашивал
  уже освобождённый RenderTargetBitmap и завершал процесс с ObjectDisposedException.
  Теперь рендер сохраняется в PNG, а принадлежащий буферу transfer создаёт независимый
  Bitmap для каждого запроса. Закрытие окна истории не обрывает владение буфером.
  Ошибка копирования отображается сообщением; прошлое сообщение не попадает в новый снимок.

## Воспроизведение и проверка

`dotnet test tests/EliteSIP.App.Linux.Tests --filter 'FullyQualifiedName~Snapshot_survives|FullyQualifiedName~Offline_choice'`
до исправления: два падения, включая точный ObjectDisposedException из пользовательского crash.log.
После исправления: проверки проходят. Проверка снимка трижды сериализует полученное
изображение после возврата обработчика и закрытия окна, освобождая каждую полученную копию.

Полный набор: `dotnet test tests/EliteSIP.App.Linux.Tests --no-restore`: **93 прошли, 0 ошибок, 0 пропусков** (19 секунд).
Модель: `dotnet test core/tests/EliteSIP.App.Core.Tests --no-restore`: **121 прошёл, 0 ошибок**.
Проверяются высота языка, светлые/тёмные popup, живые галочки отключения,
геометрия истории и отсутствие теней во всём календаре. Проверки списков и истории отслеживают ошибки привязок;
проверка меню профиля отслеживает живые привязки после инициализации панели. Её прежние
сообщения о пустых необязательных слотах разговора/активности не относятся к этому меню.

Нативная проверка Cinnamon/X11: `ELITESIP_TEST_HISTORY=1 dotnet run --project tools/TrayProbe`.
После закрытия истории отдельный процесс GTK трижды запросил снимок: каждый раз 1404×868,
процесс приложения остался жив. Стенд использует вымышленные записи и не запускает SIP/аудио.
Он заменяет буфер тестовым изображением. Wayland отдельно не проверялся.

Приложенные PNG в `history-fixes-2026-11-16/` сняты нативным стендом или headless Skia
на тех же шаблонах продукта; исходных пользовательских профилей в них нет.

Исходные шаблоны Avalonia для проверки приоритетов и контракта частей:
[ComboBox](https://github.com/AvaloniaUI/Avalonia/blob/12.1.3/src/Avalonia.Themes.Simple/Controls/ComboBox.xaml),
[MenuItem](https://github.com/AvaloniaUI/Avalonia/blob/12.1.3/src/Avalonia.Themes.Simple/Controls/MenuItem.xaml).

## Дополнения после проверки звука и входящих

Из того же Windows-коммита адаптированы `Theme/ProcessingPreview.cs`,
`RecordingWaveform.cs`, свойства кистей `LevelMeter.cs` и самопроверка из `SettingsWindow.xaml`.
Уровень показан столбиками, шум — одиночным сохранённым пиком, чужие голоса —
силуэтами с приглушёнными соседними людьми. Неактивная иллюстрация серая,
активный результат зелёный; размеры 102×24. Это статическая схема обработки.
Самопроверка использует настоящие уровни микрофона: 24 отсчёта, корень уровня,
столбики 3 точки через 5, высота 25. Кнопка показывает запись/стоп и подпись пятисекундной записи.
Обе шкалы используют Windows-кисти; при нулевом уровне пик сбрасывается.

В управлении удалены 16 декоративных обёрток вокруг TextBox. Осталась одна
фирменная рамка поля вместо сочетания тёмной обёртки и контрастной рамки SimpleTheme.
Общие цвета/скругления полей также применяются в остальных настройках.

У входящего окна внешний контур прямоугольный, как поверхность окна X11.
Скругление внутренней карточки сохранено. Блок имени/номера центрирован по вертикали;
MaxHeight=60 и фиксированная высота строки удалены, чтобы заголовок раздачи с emoji
не обрезался. Размер окна по-прежнему измеряется до показа; проверка приёма и
ограничения доступности кнопок не изменены.

Регрессионная проверка Incoming_identity до исправления: 2 падения на геометрии.
После: обе карточки проходят проверку центра и отсутствия схлопнутых строк.
Нативные PNG `incoming-*-x11.png` сняты отдельным GDK/X11-процессом с реальной
поверхности окна, без захвата курсора или пользовательских данных: раздача 360×216,
звонок по сделке 360×263, WindowDecorations=None.
